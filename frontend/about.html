About This Project

Understanding how the UK’s energy generation and emissions data can be managed and analysed through a relational database system.

Project Overview

UK Energy Monitor is a database system created to store and manage UK energy generation and carbon emission data. This system shows how real data taken from government datasets can be effectively utilised to create a useful relational database and presented on a simple web site.

Why This System Was Built

This system was built to allow analysts to easily view UK energy and emissions data using a robust and user-friendly system. It allows them to view and track generation and emissions records over time, and provide them with valuable comparisons from aggregated data created by SQL reports.

Data Sources

The database design is mainly based on publicly available statistics from the UK Department for Energy Security and Net Zero (DESNZ) and other UK government datasets.

UN Sustainable Development Goal

This project aligns with UN SDG 7 — Affordable and Clean Energy by supporting monitoring of the UK’s progress toward cleaner energy production and reduced carbon emissions.
